# 🎯 AI Chat Commands Guide

Deze AI chat heeft nu **5 krachtige commando's** die je kunt gebruiken!

## ✅ 1. Compare Projects

**Wat het doet:** Vergelijk twee projecten side-by-side

**Gebruik:**
```
"Compare MindfulMoments and BreathEasy"
"Compare MindfulMoments with BreathEasy"
"Compare MindfulMoments vs BreathEasy"
```

**AI Response:**
- Side-by-side vergelijking
- Overeenkomsten
- Verschillen
- Use cases voor elk project
- Unieke features
- Beide projecten worden getoond

**Voorbeeld:**
```
User: "Compare MindfulMoments and BreathEasy"

AI: "Here's a comparison of MindfulMoments and BreathEasy:

**MindfulMoments** is a mobile app focusing on mood tracking and personalized mindfulness exercises tailored to your emotional state. It's perfect for daily mental health maintenance and understanding your emotional patterns over time.

**BreathEasy** is a web application specifically designed for anxiety relief through breathing techniques and guided exercises. It provides immediate relief during stressful moments.

**Similarities:** Both focus on mental health and stress management through accessible digital tools.

**Key Differences:**
- MindfulMoments: Long-term mood tracking, mobile-first, broader focus
- BreathEasy: Immediate anxiety relief, web-based, breathing-specific

Choose MindfulMoments for ongoing mental health tracking, BreathEasy for quick anxiety relief when you need it."

Projects shown: MindfulMoments + BreathEasy
```

## 🎯 2. Filter by Criteria

**Wat het doet:** Filter projecten op specifieke criteria

**Gebruik:**
```
"Filter by mobile apps"
"Show me mobile apps"
"Show me only web applications"
"Filter by AI projects"
"Show me mobile apps for mental health"
```

**Criteria die werken:**
- `mobile` → Mobile apps
- `web` → Web applications
- `AI` → AI-powered projects
- Combinatie: "mobile apps for stress"

**AI Response:**
- Toegepaste filter wordt uitgelegd
- Alleen matching projecten
- Aantal resultaten

**Voorbeeld:**
```
User: "Show me mobile apps for stress"

AI: "Here are mobile apps specifically designed for stress management:

I've filtered the archive for mobile applications that help with stress relief. These apps are all mobile-first and focus on accessible stress management tools."

Projects shown: Only mobile apps tagged with stress/mental health
```

## 🔗 3. Similar Projects

**Wat het doet:** Vind projecten die lijken op een specifiek project

**Gebruik:**
```
"Similar to ConnectCircle"
"Show me similar projects"
"Projects like BreathEasy"
"Similar projects to what you just showed"
"Alternatives to MindfulMoments"
```

**AI Response:**
- 3-5 vergelijkbare projecten
- Uitleg wat ze gemeen hebben
- Shared tags/features
- Waarom ze als alternatief dienen

**Voorbeeld:**
```
User: "Similar to ConnectCircle"

AI: "Here are projects similar to ConnectCircle, which all focus on social connection and peer support:

**SafeSpace** creates anonymous peer support forums for students to share struggles safely. Like ConnectCircle, it emphasizes community building and peer interaction, but with added anonymity.

**FitnessForMind** combines physical and mental health through community challenges. While ConnectCircle focuses on interests, this adds a fitness component to social connections.

**GratitudeJournal** can be shared with friends for mutual support. It builds connections through shared positive psychology practices."

What they share: Community building, peer support, reducing isolation through technology.
```

## ⚡ 4. Quick Facts

**Wat het doet:** Geef een bullet-point overzicht van een project

**Gebruik:**
```
"Quick facts about BreathEasy"
"Facts about MindfulMoments"
"Tell me quick facts about TherapyMatch"
```

**AI Response:**
- Bullet-point lijst (•)
- Purpose/Doel
- Target audience
- Key features (3-5)
- Type (mobile/web)
- Main benefit

**Voorbeeld:**
```
User: "Quick facts about BreathEasy"

AI: "Here are the quick facts about BreathEasy:

• **Purpose:** Anxiety relief through breathing techniques
• **Type:** Web application
• **Target:** Students and anyone experiencing stress/anxiety
• **Key Features:**
  - Guided breathing exercises
  - Real-time anxiety tracking
  - Multiple breathing techniques (4-7-8, box breathing, etc.)
  - Progress tracking
• **Best For:** Immediate stress relief during anxious moments
• **Access:** Browser-based, no installation needed"

Project shown: BreathEasy with full details
```

## 💝 5. Search by Use Case / Emotional Context

**Wat het doet:** Begrijp emotionele situaties en stel passende projecten voor

**Gebruik:**
```
"I'm stressed about exams"
"I feel lonely"
"I can't focus on my work"
"I'm dealing with burnout"
"Help me with anxiety"
"I feel overwhelmed"
"I'm struggling with sleep"
```

**Emoties/situaties die worden herkend:**
- Stressed / Overwhelmed
- Anxious / Worried
- Lonely / Isolated
- Burnout / Exhausted
- Can't focus / Concentrate
- Depressed / Sad
- Tired / Exhausted
- Can't sleep

**AI Response:**
- Empathische, begripvolle toon
- Projecten die SPECIFIEK helpen met die situatie
- Uitleg HOE elk project helpt
- Praktische suggesties

**Voorbeeld:**
```
User: "I'm stressed about exams"

AI: "I understand exam stress can be overwhelming. Here are projects that can specifically help you manage study-related stress:

**StudyFlow** uses the Pomodoro technique with built-in stress management. It helps you break down study sessions into manageable chunks, preventing overwhelm while keeping you productive during exam prep.

**BreathEasy** provides quick anxiety relief when you feel exam panic setting in. Use it for 5-minute breathing breaks between study sessions.

**MindfulMoments** can help you track your stress levels during exam period and suggests personalized exercises based on how you're feeling each day.

These tools work together: Use StudyFlow for structure, BreathEasy for quick relief, and MindfulMoments for ongoing stress tracking."

Projects shown: StudyFlow, BreathEasy, MindfulMoments with detailed "how it helps" explanations
```

## 💡 Tips & Tricks

### Combineer Commando's:
```
"Show me mobile apps for stress" → Filter
"Now compare the top 2" → Compare
"Similar to the first one" → Similar
```

### Natural Language:
Je hoeft geen exacte syntax te gebruiken! De AI begrijpt:
- "Which one is better, A or B?" → Compare
- "Got anything like this?" → Similar
- "Just the basics about X" → Quick Facts
- "I need help focusing" → Use Case

### Follow-up Vragen:
Na elk commando kun je doorvragen:
```
User: "Quick facts about BreathEasy"
AI: [Shows facts]
User: "Tell me more about the breathing techniques"
AI: [Detailed explanation]
```

## 🎯 Best Practices

**1. Be Specific:**
- ✅ "Compare MindfulMoments and BreathEasy"
- ❌ "Compare them" (zonder context)

**2. Use Project Names:**
- The AI remembers projects shown earlier in conversation
- You can refer to them by name

**3. Combine Search + Commands:**
- First search: "mental health projects"
- Then compare: "compare the first two"

**4. Express Your Needs:**
- Don't hesitate to share emotions
- "I feel stressed" gets better results than "stress projects"

## ❓ Troubleshooting

**"AI doesn't recognize my command"**
- Try different phrasing
- Be more explicit: "compare X and Y" instead of "compare these"

**"Wrong projects shown"**
- Add more context: "mobile apps for stress" instead of just "mobile apps"
- Use specific project names

**"Not empathetic enough"**
- Start with "I'm" or "I feel" for use case detection
- Example: "I'm stressed" vs "stress projects"
